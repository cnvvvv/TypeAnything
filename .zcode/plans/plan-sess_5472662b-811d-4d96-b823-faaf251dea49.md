## 执行步骤

### 第 0 步:安装缺失依赖

通过 winget / 官方脚本安装:
1. **Windows SDK 10**(含 rc.exe) — winget 安装最新版
2. **xmake** — `winget install Xmake-io.Xmake`
3. **Boost 1.84** — 用 weasel 自带的 `install_boost.bat`(会自动下载并编译,约 20-40 分钟),或下载预编译版到 `C:\local\boost_1_84_0`

### 第 1 步:获取 librime 完整源码
由于 submodule 命令不生效,手动操作:
```
git clone https://github.com/rime/librime.git third_party/weasel/librime_tmp
# 把 librime_tmp 的内容合并到 librime/(保留我们的 plugins/typeanything/)
```
完成后 `librime/` 应有完整的 `build.bat`、`CMakeLists.txt`、`src/`、`deps/`、`cmake/` 等。

### 第 2 步:创建 weasel 的 env.bat
从 `env.bat.template` 复制并配置:
```bat
set BOOST_ROOT=C:\local\boost_1_84_0   (或实际安装路径)
set BJAM_TOOLSET=msvc-14.3              (VS2022 = v143,不是 14.44)
set PLATFORM_TOOLSET=v143
```

### 第 3 步:修正硬编码路径
修改 `third_party/weasel/` 下 4 个文件,把 `D:\hrdai\aiForType\third_party\weasel` 改为 `D:\UGit\TypeAnything\third_party\weasel`:
- `run_build_weasel.py` 行 10(还有拼写错误 `hrdaiiForType`)
- `run_via_python.py` 行 12
- `debug_env.bat` 行 2
- `debug_env2.bat` 行 2

### 第 4 步:编译 librime → rime.dll
```
cd third_party\weasel
.\build.bat boost     # 一次性,编译 Boost(如果没装预编译版)
.\build.bat librime   # → dist\lib\rime.dll (已合并 typeanything 插件)
```
这会先编译 deps(glog/leveldb/marisa/opencc/yaml-cpp),再编译 librime 本体,输出在 `librime\dist\lib\rime.dll`。

### 第 5 步:编译 Weasel 二进制
```
cd third_party\weasel
.\_build_weasel_xmake.ps1   # 或 run_build_weasel.py
```
产出 `build\windows\x64\release\` 下的 `weaselx64.dll`、`WeaselServer.exe`、`WeaselDeployer.exe`。

### 第 6 步:编译 ta-settings.exe
```
cd tools\ta-settings
.\_build.ps1    # → build\windows\x64\release\ta-settings.exe
```

### 第 7 步:准备 Rime 基础数据(给 installer)
`_stage_embed.ps1` 第 48 行需要 `C:\Program Files\Rime\weasel-0.17.4\data\`(default.yaml/luna_pinyin/opencc 等)。两个选择:
- **方案 A**:先安装一次官方小狼毫 0.17.4(最可靠,数据完整)
- **方案 B**:从 weasel 的 `librime/data/minimal/` + 手动补齐缺失文件(fallback 路径,但可能缺 key_bindings/punctuation)

### 第 8 步:编译 ta-installer.exe
```
cd tools\ta-installer
.\_stage_embed.ps1   # stage 所有 embed 资源 + 编译 installer.rc
.\_build.ps1         # → build\windows\x64\release\ta-installer.exe
```

## 风险与注意事项
- **耗时**:Boost 编译约 20-40 分钟,librime deps 约 10-20 分钟,总计可能 1-2 小时
- **MSVC 工具集**:必须用 `v143` / `msvc-14.3`,不能用 `v144` 或 `msvc-14.44`
- **网络**:需要从 GitHub clone librime、下载 Boost,网络需通畅(可用 gitee 镜像替代 GitHub)
- **第 7 步的数据文件**:如果选方案 B,可能遇到 schema 编译失败,需逐步排查
